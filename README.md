# Glyvia

Glyvia 的公开网站。中文为默认语言，英文页面使用 `?lang=en`。

Glyvia 是一款无须扎针的血糖监测产品。把传感器放在舌下，读取日常分泌的唾液，再结合针对个人和当下状态的模型，在手机或小程序里显示血糖变化的趋势，供健康管理参考。使用的人和购买的人，可以不是同一位。

检测到唾液里的葡萄糖，并不等于用唾液估计血糖。Glyvia 提供的是辅助性趋势信息。它不能替代指尖采血或持续葡萄糖监测（CGM），也不用于诊断或调整胰岛素。

## 本地预览

在仓库根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

- [中文](http://127.0.0.1:4173/)
- [English](http://127.0.0.1:4173/?lang=en)

站点文件在 `dist/`：`index.html`、`css/`、`js/`、`assets/`。首页的葡萄糖分子使用随站点提供的 Three.js（`dist/js/vendor/three.min.js`）。若浏览器没有 WebGL 或 JavaScript，页面会显示 `dist/assets/glucose-still.jpg`。系统开启「减少动态效果」时，只渲染一帧静止画面，不再旋转。

页面上的联系表单不会发送或保存留言，并会拒绝看起来像个人健康信息的内容。本站未公布电子邮箱。

公开统计只引用国际糖尿病联盟《糖尿病地图集》第 11 版中的数字：2024 年全球约有 5.89 亿名 20–79 岁成人患有糖尿病。该数字在页面上标注为公开数据，不是 Glyvia 的产品数据。
